The Basics

What is Machine Learning?

Machine Learning lets a computer find patterns in data and use them to make predictions or discover structure — without being explicitly programmed with fixed rules. Broadly, it splits into two families, both demonstrated in this project.

Supervised

Learning with labeled answers

The model is trained on examples that already have a known outcome (a price, a pass/fail label) and learns the relationship between inputs and that outcome.

  • Linear Regression — predicts a continuous number
  • Logistic Regression — predicts a category
Unsupervised

Learning without answers

The model only sees the input data — no labels — and must discover natural groupings or structure on its own.

  • K-Means Clustering — groups points by similarity
  • Hierarchical Clustering — builds a tree of nested groups
