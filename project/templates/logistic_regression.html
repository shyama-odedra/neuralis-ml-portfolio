Logistic Regression fits an S-shaped (sigmoid) curve instead of a straight line, so its output is always squeezed between 0 and 1 — a probability. It computes a weighted sum of the inputs, z = b₀ + b₁·hours + b₂·attendance, then passes that through the sigmoid function to get a probability of passing. If that probability is ≥ 0.5, the model predicts "Pass"; otherwise "Fail". The line where the probability is exactly 0.5 is the decision boundary shown on the chart.
