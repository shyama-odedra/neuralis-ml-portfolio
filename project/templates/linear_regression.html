Linear Regression finds the straight line (or, with multiple features, a flat plane) that best fits the training data by minimizing the squared distance between the line and every actual data point. Formally, it estimates coefficients price = b₀ + b₁·area + b₂·bedrooms + b₃·age that minimize the total squared error. Once fitted, the same formula is used to predict the price of any new house.
